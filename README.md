# Аналитика заказов — обзор для руководства

Vue 3.5.22 + D3 7.9.0, без сборки. Библиотеки хранятся в `vendor/`; данные не отправляются на сервер. Для шрифта используется Google Fonts с системным запасным вариантом.

## Запуск

```sh
npm run dev
```

Открыть http://127.0.0.1:5173. Альтернатива без Node.js: `python3 -m http.server 5173 --bind 127.0.0.1`.

## Структура

- `index.html` — интерфейс и шаблон Vue.
- `app.js` — состояние, расчёт метрик, фильтры, D3-графики, CSV-экспорт.
- `style.css` — оформление и адаптивная сетка.
- `data/orders.csv` — копия исходного датасета.
- `vendor/` — локальные версии Vue и D3.

## Возможности

Период по месяцам, быстрые диапазоны, категории, статусы, детализация месяца нажатием на график, поиск и сортировка товаров, пагинация, экспорт месячного отчёта с текущими фильтрами. Поиск ограничивает только таблицу товаров. Сброс возвращает последние 24 месяца и доставленные заказы.

Заказы считаются по уникальному order_id. Сумма трат — сумма amount после скидок. Средний процент скидки — среднее discount / price × 100, взвешенное по quantity для строк с price > 0. Экономия — сумма discount × quantity. Все метрики пересчитываются с учётом фильтров. Услуги учитываются в общей сумме трат, но исключены из товарного рейтинга. Частота товара — число уникальных заказов; доля трат товара считается без услуг. Отменённые заказы по умолчанию исключены; их суммы при включении отражают данные CSV, а не факт оплаты.

Месяцы без заказов сохраняются в графике с нулевыми значениями. График показывает весь выбранный диапазон; выбор одного месяца ограничивает остальные блоки. Изображения товаров заменены эмодзи и не требуют загрузки внешних ресурсов.

Дашборд анализирует заказы всех пользователей. В CSV нет идентификатора клиента, поэтому показатели не интерпретируются как поведение одного человека. Верхняя и боковая навигация убраны; категории представлены горизонтальным рейтингом с суммами и долями.

## Соответствие критериям

- По умолчанию сентябрь 2024 — август 2026: последние 24 месяца доступных данных.
- Карточки по умолчанию показывают последний день с данными в выбранном диапазоне; селектор позволяет выбрать последний месяц или весь период. В режиме дня/месяца показывается, сравнение с предыдущим календарным месяцем и итог выбранного периода. Мини-графики показывают динамику каждой основной метрики; большой график переключает заказы, траты и скидку.
- Товарный график показывает количество единиц и траты рядом на независимых шкалах, с эмодзи для каждой позиции. Пагинация, поиск и сортировка синхронизированы с таблицей.
- Наведение, фокус клавиатуры и нажатие на товар показывают тултип с месячной динамикой цены после скидки и до скидки. Цена взвешена по количеству; месяцы без покупок остаются разрывами. История сохраняет весь диапазон при детализации одного месяца.
- Категории: уникальные заказы, количество, траты, средняя скидка и доля трат. Один заказ может попасть в несколько категорий.

Дата последнего дня определяется до фильтра категории и статуса, чтобы значения разных сегментов оставались сопоставимыми. Если у сегмента в этот день нет заказов, отображаются нули. Выбор месяца на графике ограничивает активную выборку во всех режимах карточек.
