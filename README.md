# Аналитика заказов — обзор для руководства

Vue 3.5.22 + D3 7.9.0, без сборки. Библиотеки хранятся в `vendor/`; данные не отправляются на сервер. Для шрифта используется Google Fonts с системным запасным вариантом.

## Запуск

```sh
npm run dev
```

Открыть http://127.0.0.1:5173. Альтернатива без Node.js: `python3 -m http.server 5173 --bind 127.0.0.1`.

## Структура

- `index.html` — интерфейс и шаблон Vue.
- `app.js` — состояние, расчёт метрик, фильтры, D3-графики, CSV-экспорт.
- `style.css` — оформление и адаптивная сетка.
- `data/orders.csv` — копия исходного датасета.
- `vendor/` — локальные версии Vue и D3.

## Возможности

Период по месяцам, быстрые диапазоны, категории, статусы, детализация месяца нажатием на график, поиск и сортировка товаров, пагинация, экспорт месячного отчёта с текущими фильтрами. Поиск ограничивает только таблицу товаров. Сброс возвращает последние 12 месяцев и доставленные заказы.

Заказы считаются по уникальному order_id. Сумма трат — сумма amount после скидок. Средний процент скидки — среднее discount / price × 100, взвешенное по quantity для строк с price > 0. Экономия — сумма discount × quantity. Все метрики пересчитываются с учётом фильтров. Услуги учитываются в общей сумме трат, но исключены из товарного рейтинга. Частота товара — число уникальных заказов; доля трат товара считается без услуг. Отменённые заказы по умолчанию исключены; их суммы при включении отражают данные CSV, а не факт оплаты.

Месяцы без заказов сохраняются в графике с нулевыми значениями. График показывает весь выбранный диапазон; выбор одного месяца ограничивает остальные блоки. Изображения товаров заменены эмодзи и не требуют загрузки внешних ресурсов.

Дашборд анализирует заказы всех пользователей. В CSV нет идентификатора клиента, поэтому показатели не интерпретируются как поведение одного человека. Верхняя и боковая навигация убраны; категории представлены горизонтальным рейтингом с суммами и долями.
